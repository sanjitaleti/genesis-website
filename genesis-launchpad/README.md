# Genesis Launchpad

A murdered-out black luxury marketing site for a fictional AI infrastructure product.
Next.js 15 (App Router) · TypeScript (strict) · Tailwind CSS · Framer Motion.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
```

## Pages
`/` · `/features` · `/about` · `/solutions` · `/pricing` · `/contact`

## Design system
See [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md) — color tokens, type scale, glass recipe,
animation springs, and the anti-slop manifesto. Accents are **cyan + pink only**. No purple.

## Bonus
[`preview.html`](./preview.html) — a single self-contained file (Tailwind via CDN) that
mirrors the home page for instant preview without a build step.
