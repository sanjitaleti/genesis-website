# Claude Skill: Fluid Motion

## Core Philosophy
Web animation must feel fluid. Avoid linear movements.

## Golden Springs
- High Energy: `type: "spring", stiffness: 400, damping: 25`
- Smooth Fluid: `type: "spring", stiffness: 300, damping: 30`

## Code Patterns
- Use x, y, scale, opacity.
- Use staggerChildren for lists.
